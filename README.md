# Mini juego de peleas en HTML5

Proyecto simple de pelea 2D hecho con **HTML5 Canvas + JavaScript vanilla**.

## Cómo jugar
1. Abre `index.html` en tu navegador.
2. Controla a los dos jugadores en el mismo teclado.

### Controles
- **Jugador 1:** `A/D` mover, `W` saltar, `F` golpe rápido, `G` golpe fuerte.
- **Jugador 2:** `←/→` mover, `↑` saltar, `K` golpe rápido, `L` golpe fuerte.

## Mecánicas
- Barra de vida para cada jugador.
- Temporizador de 60 segundos.
- KO por daño o victoria por puntos cuando el tiempo termina.
- Botón para reiniciar combate.
